# Job access by transit and car

An interactive map of how many jobs the residents of each block group can reach within 30 minutes by
transit and by car, in 84 U.S. metropolitan areas, 2023–2025.

**Map:** https://smh172.github.io/transit-access-map/

The access values come from the panel described in Sierra Arnold, "The Evolution of Transit Access to
Jobs in American Cities" (https://smh172.github.io/evolution-transit-access/evolution_transit_access.pdf),
which describes the sources and methods. The map's "About the data" panel gives the definitions and the
coverage.

This repository holds the published page only: `index.html`, `app.js`, `style.css`, and the data files
the page draws (`data/`).
